# Suggested GitHub Discussions categories

Enable **Discussions** on the repository (Settings → Features → Discussions),
then create these categories:

| Category | Format | Purpose |
|---|---|---|
| 📣 Announcements | Announcement | Releases, paper status, dataset updates (maintainers post) |
| 🙏 Q&A | Question / Answer | "How do I…" questions about install, training, reproduction |
| 💡 Ideas | Open discussion | Feature ideas, new baselines, extensions |
| 🔬 Methods & Results | Open discussion | Discussion of the architecture, metrics, ablations |
| 🧩 Reproducibility | Q&A | Help reproducing results; environment/CUDA/seed issues |
| 🙌 Show & Tell | Open discussion | Downstream uses, applications to other datasets |
| 💬 General | Open discussion | Anything that doesn't fit above |

Keep **bug reports** and concrete **feature requests** in Issues (templates
provided); use Discussions for open-ended research conversation.
