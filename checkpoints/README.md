# `checkpoints/` — Trained model weights

Per-fold ensemble checkpoints produced by training, e.g.
`ins_hdgs_cmt_headline/fold_XX/member_Y.pt`.

Weights are **not committed to this repository** (too large for a source
tree). Regenerate them locally with `reproducibility/train.sh`, or download a
pretrained release from the repository's GitHub Releases page, if published.
