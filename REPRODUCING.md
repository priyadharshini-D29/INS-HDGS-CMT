# Reproducing the INS-HDGS-CMT results

Written for researchers who want to verify or re-run the results of the manuscript ("What Does a Multimodal EEG–Eye-Tracking Engagement Decoder Learn?").
This branch (`paper-sources`) is a sources-only snapshot: all code, per-fold results
(CSV), statistics and manuscript TeX are included; binaries (model checkpoints,
compiled PDFs, rendered figures) are not, and are regenerated by the steps below.

There are two levels of reproduction. Level 1 needs no GPU and takes minutes;
Level 2 retrains everything from the public dataset.

---

## Level 1 — verify every reported number from the committed per-fold files

Every statistic in the paper (means, SDs, paired Wilcoxon tests, Holm corrections,
bootstrap CIs, effect sizes, calibration) is computed from per-fold CSVs that are
committed in this branch. Retraining is **not** required to check any reported number.

| Paper item | Committed source | Recompute with |
|---|---|---|
| Table 4 / 5 (tuned baselines, engagement index) | `results/baselines/dl_tuned/losocv_*.csv` | `results/statistics/paired_effect_sizes.csv`, `docs/STATISTICS_REPORT` conventions |
| Table 6 (component ablation) | `results/ablation/*/losocv_*.csv` | `scripts/analysis/compare_component_ablation.py` |
| Table 7 (product-selection label, six models) | `results/label_product/baselines/dl_tuned/losocv_*.csv`, `results/label_product/ablation/abl_full/` | `scripts/statistics/tests_product_label.py` |
| Incremental validity over dwell | `results/label_product/baselines/dl_tuned/fold_probs/` | `scripts/statistics/tests_product_label.py` (block 4) |
| Table S8 (fixed-budget baselines) | `results/baselines/dl/losocv_*.csv`, `fold_probs/` | `scripts/statistics/table_s8_fixed_budget.py` |
| Table S10 / S14 (paired tests vs decoder) | `results/statistics/paired_effect_sizes.csv` | — |
| Table S15 (label recoverability probes) | `results/statistics/label_leakage_audit*.csv` | `scripts/analysis/label_leakage_audit.py` |
| Fold-wise probe check (Section 3.2 / Table S17 caption) | `results/statistics/label_leakage_audit_foldwise.csv` | `scripts/statistics/foldwise_probes.py` |

The fold-level files carry one row per held-out participant, keyed by
`test_subject`, so any comparison can be re-paired independently.

## Level 2 — full retraining from the public dataset

### Environment

- Python 3.12+; install PyTorch first for your CUDA/CPU target, then
  `pip install -r requirements.txt` (see the header of `requirements.txt`).
- Original submission runs: Python 3.12, PyTorch 2.7.1, CUDA 12.6.
  Later runs: PyTorch 2.11 (cu128) on RTX 5060 / 8x A100. Metrics agreed
  across both environments within the run-to-run spread reported below.
- On Windows set `PYTHONUTF8=1`.

### Data

The NeuMa dataset is public (CC BY 4.0): https://doi.org/10.6084/m9.figshare.22117124
(raw release used here; dataset descriptor DOI 10.6084/m9.figshare.22117001).
No participant data is redistributed in this repository. Run the pipeline stages
under `src/data_pipeline/` in numeric order (01_validation … 06_dataset_aggregation).
The engagement label is constructed by
`src/data_pipeline/04_segmentation/engagement_phase3d.py`; the product-selection
epochs by `src/data_pipeline/04_segmentation/product_epoching.py`.

### Training commands

All seeds are 42 (`PYTHONHASHSEED=42`; Python/NumPy/PyTorch generators). The decoder
prediction is a 5-member ensemble (members differ by initialisation seed).

```bash
# Decoder (LOSOCV), ablations, audit, attribution
python src/model/main.py                 # LOSOCV
python src/model/main.py --ablation
python src/model/main.py --audit
python src/model/main.py --explain

# Tuned baselines (engagement index), from src/model/:
python baselines/run_baselines.py --models all --tune 12 --early-stop \
    --out-dir <repo>/results/baselines/dl_tuned

# Late fusions of standard parts : add eegnet_et, shallow_et to --models.

# Product-selection label :
NEUMA_LABEL_SOURCE=product python baselines/run_baselines.py \
    --models eegnet,shallow,et_lstm,eegnet_et,shallow_et \
    --tune 12 --epochs 250 --patience 30 --early-stop \
    --out-dir <repo>/results/label_product/baselines/dl_tuned

# Fold-wise label with the matched validation rule :
NEUMA_LABEL_FOLDWISE=1 NEUMA_VAL_RULE=matched python baselines/run_baselines.py \
    --models eegnet,shallow,et_lstm --tune 12 --early-stop \
    --out-dir <repo>/results/baselines/dl_tuned_v2

# Long runs can be sliced across GPUs and merged:
#   --folds A-B on each worker, then
python scripts/statistics/merge_fold_parts.py --out-dir <dir> --models <list> --expected 37
```

`docs/REPRODUCIBILITY_CHECKLIST.md` lists expected outputs, directory layout and
hardware timings.

### What to expect

- **Determinism:** identical machines and library versions reproduce runs closely;
  across GPUs/toolkits, bitwise identity is not guaranteed. The measured
  run-to-run spread of the full decoder over three same-seed trainings is
  **0.02 balanced accuracy (0.719–0.740) / 0.02 ROC-AUC (0.863–0.879)**;
  differences within this band are the documented noise floor, and the paper's
  conclusions are stated relative to it.
- The tuned standard baselines are single models per fold (no ensemble); the
  decoder rows are 5-member ensembles — both stated in the table captions.
- Checkpoints are deliberately not distributed; every checkpoint regenerates
  from the commands above, and no reported statistic depends on a distributed
  binary.
