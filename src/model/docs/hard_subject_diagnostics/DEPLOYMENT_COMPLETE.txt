================================================================================
🔧 KEY COMPONENTS
================================================================================

10 Diagnostic Analyses:

[1] Probability Histogram
    → Visualizes predicted probabilities by true class
    → Determines: Are classes separable?

[2] ROC Curve
    → Area Under Curve (AUC) regardless of threshold
    → Determines: Is ranking fundamentally good?

[3] Precision-Recall Curve
    → Precision vs recall trade-off
    → Determines: Is there meaningful separation?

[4] Threshold Sweep
    → Metrics (Acc, Bal.Acc, F1, MCC) vs threshold
    → Determines: What's the optimal threshold?

[5] Confusion Matrix
    → True/false positives/negatives
    → Determines: What are the error patterns?

[6] Calibration Analysis
    → Predicted vs actual probability
    → Determines: Are probabilities trustworthy?

[7] Embedding Visualization
    → t-SNE/UMAP projection of learned features
    → Determines: Do classes cluster in latent space?

[8] Subject Shift Detection
    → Mahalanobis/cosine distance to training distribution
    → Determines: Is subject an outlier?

[9] Ranking Analysis
    → Individual predictions sorted by probability
    → Determines: Are individual rankings reasonable?

[10] Automatic Diagnosis
     → Failure mode classification (A-E)
     → Determines: What's wrong and what to do about it?

          done

PHASE 2: IMPLEMENT EASY FIXES (1-2 hours)
───────────────────────────────────────────

  For Mode A (Threshold Issue):
    → Apply best_threshold.json to inference
    → Re-evaluate (~15 min)

  For Mode B (Calibration Issue):
    → Apply temperature scaling
    → Re-evaluate (~30 min)

  For Mode C (Distribution Shift):
    → Collect subject-specific data
    → Fine-tune model (~2-4 hours)

  For Mode D (Label Noise):
    → Manual review of samples
    → Correct obvious errors (~1-2 hours)

  For Mode E (Representation Failure):
    → Deep debugging session (~4-8 hours)
    → May require architecture changes


PHASE 3: VALIDATE IMPROVEMENTS (30-45 min)
────────────────────────────────────────────

  Step 1: Re-run diagnostics after fixes
  Step 2: Compare metrics to baseline
  Step 3: Verify improvements per failure mode
  Step 4: Iterate if needed
